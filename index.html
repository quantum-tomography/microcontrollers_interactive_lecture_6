What is the W (Working) Register?

Accumulator

The W register stands for Working Register. It is a core 8-bit CPU register used by the Arithmetic Logic Unit (ALU) to hold one of the operands during processing. Following an operation, the ALU can also write the computation result directly back into the W register.

Architectural Note: While Microchip uses the term "Working Register" for PIC microcontrollers, in most other computer architectures this register is referred to as the Accumulator.

The Status Register: STATUS

Flags

The STATUS register contains status bits known as flags. These bits reflect the outcome of ALU operations:

Z (Zero Flag)
Zero Result Flag

Set to 1 if the operation result is zero. During subtraction, Z=1 indicates both operands were equal.

C (Carry Flag)
Carry Out Flag

Set to 1 if an arithmetic operation causes a carry out from the most significant bit (Bit 7).

DC (Digit Carry)
Half-Carry Flag

Set to 1 if a carry occurs from the lower nibble to the upper nibble (from Bit 3 to Bit 4).

Flag Affect Rules: Arithmetic instructions (ADD, SUB) affect all three status flags (Z, DC, C), whereas logical operations (AND, XOR) affect only the Z flag.

Note: When an instruction "affects" a flag, it updates its value depending on the operation's result (clearing it to 0 or setting it to 1).

Key Concepts

  • Flag: A single status bit (1 or 0) indicating a specific CPU condition.
  • Nibble: A 4-bit half-byte block.
  • Program Testing: Reading status flags to make conditional jump decisions.

Program Execution & Branching (Conditional vs Unconditional)

Under normal execution, instructions are fetched and executed sequentially. A branch or jump alters this normal sequential flow.

Conditional Jumps

Executed only after testing a specific condition (e.g., checking if flag $Z=1$). If true, execution branches to a new target; if false, sequential execution continues.

Unconditional Jumps

Execution branches directly without testing any conditions. Examples include calling a subroutine (CALL) or jumping directly via GOTO.

Subroutines & Code Modularity

Programs are generally structured into a main program and multiple reusable subroutines.

Benefits of Subroutines:

  • Saves Flash Memory: Frequently used routines are written once and invoked anywhere in the program.
  • Simplified Code Maintenance: Encourages clean, modular program design.

Subroutine calling (CALL) and returning (RETURN / RETFIE) rely on the hardware Stack.

Execution Flow Example

// Main Program
MAIN:
MOVLW 0x05
CALL DELAY_SUB
BSF PORTB, 0
// Subroutine
DELAY_SUB:
... delay loop ...
RETURN

Hardware Stack & Program Counter (PC)

Program Counter (PC): A 13-bit CPU register that controls the execution sequence by holding the memory address of the next instruction to fetch. On Reset, the PC initializes to address 0000h.

Hardware Stack: A dedicated internal memory block consisting of 8 levels of 13-bit registers. It automatically saves the PC return address during subroutine calls or interrupt triggers.

LIFO Operation (Last In, First Out):
  • On CALL: The current PC return address is pushed to Level 1, shifting previous entries down one level.
  • On RETURN: The address at Level 1 is popped back into PC, shifting all lower entries up one level.
  • Capacity: Supports up to 8 nested subroutine levels!

Interrupts & Vector Address

An interrupt allows external events (sensors, timers, button pushes) to instantly suspend the main program loop and execute an Interrupt Service Routine (ISR).

Interrupt Vector Address

On PIC microcontrollers, the fixed interrupt vector location is address 0004h in program memory.

Interrupt Masking

Interrupt sources can be selectively enabled or masked (disabled) via dedicated enable bits in Special Function Registers (SFRs).

I/O Ports & Direction Registers (TRIS)

Input/Output ports enable the microcontroller to interact with external circuits. PIC MCUs feature between 1 and 7 ports (named PORTA, PORTB, PORTC ... PORTG), each containing 5 to 8 I/O pins.

TRIS Data Direction Registers

Each port pin direction is controlled by its corresponding bit in the TRIS register (TRISA, TRISB, etc.):

Bit = '0'
OUTPUT Mode
Bit = '1'
INPUT Mode

Upon System Reset, all TRIS bits default to '1' (Input mode) for hardware safety.

Internal Weak Pull-up Resistors

Weak pull-up resistors ensure input pins default to a high logic level ('1') when floating or connected to open switches.

• Certain ports (e.g., PORTB) feature software-configurable internal pull-up resistors.

• When a pin is reconfigured as an output, its internal pull-up resistor is automatically disabled.

Serial vs Parallel Communication & Peripherals

Serial I/O Port

Transmits data sequentially, bit-by-bit. Requires only 2 or 3 communication lines.

Data Rate: Measured in bits per second (bps) or Baud rate. 1 bit/s = 1 Baud (e.g., 100 kilobaud = 100 Kbit/s).

Parallel Slave Port (PSP)

Interfaces directly with external microprocessors over an 8-bit data bus (typically PORTD).

Transmits all 8 bits simultaneously for high-speed short-distance parallel data transfers.

On-Chip Peripherals Summary:

Timers

Counters incremented by clock pulses or external signals. Precision depends on timer bit width.

EEPROM Memory

Non-volatile data storage up to 256 bytes. Retains data for 40 years across 1,000,000 write cycles.

ADC Module

Converts analog voltages (e.g., 1V–4V range) into binary digital words for processing.

Microcontroller Selection Criteria

While all PIC microcontrollers include timers and I/O ports by default, optional peripherals like ADC, EEPROM, and serial ports vary across product lines. Selecting an oversized MCU with unused peripherals unnecessarily increases total hardware cost.
